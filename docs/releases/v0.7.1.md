# Nova Editor v0.7.1

## What's new
- **Desktop VST3 for MPC Desktop and DAWs:** `Nova-Editor-0.7.1-macos-vst3.zip` (one file for Apple Silicon and Intel Macs, with the same touchscreen skin in the plugin window).
- **Device projects open on the computer:** the VST3 has the VST2's official replacement ID, so a project saved on the MPC with this plugin loads it in MPC Desktop (controller mode) instead of showing a missing plugin, with the same sound and settings. A project saved on the desktop opens on the MPC the same way.

## Fixed
- The desktop VST3 doesn't talk to a synth yet (the MIDI link is MPC-only); it loads with your project and keeps its settings.
